# 影片逐字稿收藏 PWA

YouTube 影片分享 → 一鍵取得逐字稿 → 本地存檔閱讀。

## 上傳到 GitHub Pages

1. 把這個資料夾裡的**所有檔案**上傳到 repo 根目錄：
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
2. Settings → Pages → Deploy from branch → main / root → Save
3. 等 1～2 分鐘，開 https://你的帳號.github.io/repo名稱/

## 安裝成 App（手機 Chrome）

1. Chrome 開上面網址
2. 右上選單 → 安裝應用程式 / 加到主畫面
3. 裝好後，YouTube 分享選單會出現「逐字稿」

⚠️ 五個檔案要在同一層；網址要 HTTPS（GitHub Pages 預設就是）。
